# CSE 111 — Introduction to Computer Science

Coursework and programming projects for **CSE 111: Introduction to Computer Science** at **Brigham Young University**.

## About the Course

CSE 111 introduces fundamental concepts of computer science with an emphasis on programming and managing program complexity. Rather than focusing solely on a particular programming language, the course explores techniques that allow programmers to think about problems at an appropriate level of abstraction.

The course primarily uses **Python 3**, while also introducing other languages and concepts later in the semester.

### Topics

Throughout the course, I will be studying concepts including:

- Programming and problem solving
- Abstraction
- Functional programming
- Data abstraction
- Object-oriented programming
- Program complexity
- The structure and interpretation of computer programs
- Writing, analyzing, and improving programs

## Learning Goals

My goal for this course is not simply to learn Python syntax. I want to develop a stronger understanding of **how to think like a programmer** and how to manage the complexity of larger programs.

In particular, I want to become better at:

- Breaking complex problems into smaller pieces
- Designing clear and maintainable programs
- Applying abstraction effectively
- Understanding how different programming paradigms approach problems
- Reading and analyzing code written by others
- Writing code that is both correct and easy to understand
- Developing stronger problem-solving skills
